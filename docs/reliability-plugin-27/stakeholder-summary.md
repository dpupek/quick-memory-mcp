# What changes for each group

**SysOps operators** can ask to resume a case and see the last verified state, the outstanding question and the next action. An explicit handoff save updates the same case record. The pilot checks that repeated saves leave one recoverable handoff.

**Campus developers** can look up a decision by case number or wording and inspect a dated source. Older notes that mention a case only in their title or body remain eligible. Results identify the project or shared origin.

**Project administrators** can grant a role, verify its effective permissions through HTTP and MCP, and see whether a failed action changed data. Service operators get a tested upgrade and restore procedure and tool-level usage measurements.

**Pilot leads** each select ten known-answer scenarios privately, score their own cohort, and record whether to expand, revise or stop. The private plugin is optional during the pilot. Disabling it returns participants to their direct MCP workflow.
